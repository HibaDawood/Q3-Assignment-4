# 🚀 Python Streamlit Production Apps & Core Assignment Suite

Welcome to this comprehensive development repository. This workspace showcases high-performance, interactive web applications built using **Python** and **Streamlit**, backed by a diverse suite of foundational programming scripts, logical modules, and core assignments.

## 🌟 Flagship Core Projects (Main Applications)

These are the primary production-grade web applications deployed live, demonstrating stateful user inputs, data processing, and modern dashboard UIs:

### 1️⃣ 🏋️‍♂️ Dynamic BMI Health Calculator
An interactive, precision-engineered health tool designed to calculate Body Mass Index (BMI) instantly based on user demographics and metrics.
* **Core Engineering Features:**
  * Supports dual-system metrics (Metric: kg/meters & Imperial: lbs/inches) with real-time value validation.
  * Dynamically computes body mass status and maps results against official WHO health classifications.
  * Provides conditional, automated health recommendations based on individual calculation profiles.

### 2️⃣ 🧠 Moodify — Interactive Mood Tracker & Analytics
A stateful mental wellness dashboard built to log daily emotional states, track psychological patterns, and promote self-reflection.
* **Core Engineering Features:**
  * Interactive mood selection vectors backed by customizable journal prompt inputs.
  * Stateful data logging that tracks daily entries to visualize emotional trends over time.
  * Delivers dynamic, AI-inspired growth-mindset quotes and automated wellness insights to uplift user states.
